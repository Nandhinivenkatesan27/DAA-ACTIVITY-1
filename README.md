Activity 1 – Data Structures & Algorithms
This activity focuses on solving fundamental Data Structures and Algorithms (DSA) problems using efficient programming techniques. The problems cover arrays, strings, searching, and subarray operations.
Problems Covered
Two Sum – Find two elements whose sum equals the given target.
Longest Substring Without Repeating Characters – Find the length of the longest substring containing unique characters.
Product of Array Except Self – Calculate the product of all elements except the current element without using division.
Maximum Subarray – Find the contiguous subarray with the maximum sum using Kadane's Algorithm.
Binary Search – Search for an element in a sorted array using the binary search technique.
Learning Objectives
Understand basic DSA problem-solving techniques.
Improve logical and algorithmic thinking.
Implement efficient solutions in Java.
Analyze time and space complexity.
Practice commonly asked coding problems.
Technologies Used
Language: Java
Concepts: Arrays, Strings, Hashing, Sliding Window, Kadane's Algorithm, Binary Search
Conclusion
This activity provides practical experience in solving commonly used DSA problems and helps develop efficient problem-solving skills for programming and technical interviews.
